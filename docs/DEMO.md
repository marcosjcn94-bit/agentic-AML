# Roteiro de demonstração

1. Inicie o Ollama com o modelo definido no YAML, a API e o Streamlit.
2. Envie um alerta sintético com o papel `sistema`.
3. Abra a fila como analista e filtre `em_risco`.
4. Mostre o dossiê mascarado, as citações e o evento de auditoria.
5. Reidentifique explicitamente, submeta o dossiê e decida como compliance officer.

Valores reais não devem ser usados na demonstração.
